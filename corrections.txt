I want to refactor the styling (CSS/Tailwind) to achieve a 'Modern, Elevated Academic Hub' aesthetic. It should remain a minimal dark theme, but it needs to feel premium, accessible, and highly interactive. Please rewrite the styling based on the following design system:

1. The Color Palette (Premium Dark Mode)

Base Background: Shift from plain flat blue to a sophisticated, deep slate/charcoal (e.g., #0F172A or #111827).

Surface/Card Backgrounds: Use slightly lighter, elevated tones (e.g., #1E293B) for resource cards, chat windows, and booking modules.

Primary Accent: Use a modern, energetic 'Academic Blue' or 'Soft Indigo' (e.g., #3B82F6 or #6366F1) for primary actions like 'Post Item', 'Send Message', or 'Book Court'.

Text: Never use pure white. Use crisp off-whites (#F8FAFC) for headings to reduce eye strain, and soft grays (#94A3B8) for descriptions and timestamps.

2. Borders & Outlines (Remove the 'Robotic' Feel)

Remove harsh, solid 1px/2px bright borders. * Replace them with 'soft glass borders' using very low-opacity whites (e.g., border: 1px solid rgba(255, 255, 255, 0.08)). This separates elements without drawing rigid boxes.

Add a smooth border-radius (e.g., 12px or 16px) to all cards, modals, and input fields to make the interface feel friendly and modern.

3. Depth & Interactivity (The 'App' Feel)

Because students will be browsing listings and clicking items, the UI needs depth.

Resting State: Give cards a subtle, wide, dark drop-shadow so they visually separate from the background.

Hover State: When a student hovers over a resource card or a user profile, it should smoothly lift upwards (e.g., transform: translateY(-4px)) with an expanding soft shadow. Add transition: all 0.3s ease for a buttery-smooth feel.

4. Typography & Spacing

This app is heavily text-based (descriptions, chats, rules). Use a highly readable, modern Sans-Serif font like Inter or Roboto.
